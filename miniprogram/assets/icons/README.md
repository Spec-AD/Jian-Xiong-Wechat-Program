# tabBar 图标说明

请在此目录放置以下图标文件（建议 81×81px，PNG 格式）：

| 文件名               | 用途              |
|----------------------|-------------------|
| home.png             | 首页默认图标      |
| home_active.png      | 首页选中图标      |
| hall.png             | 大厅默认图标      |
| hall_active.png      | 大厅选中图标      |
| profile.png          | 我的默认图标      |
| profile_active.png   | 我的选中图标      |

颜色规范：
- 默认态：#7a8fa8（蓝灰）
- 选中态：#4a90e2（蓝色）

> 提示：在图标未就位之前，tabBar 仍可正常显示文字，图标区域留空。
