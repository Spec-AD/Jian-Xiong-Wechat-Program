关于AI模块的设计，我计划提供 API 调用入口，支持Deepseek V4 Flash的调用，这个页面将实现实时对话窗口。支持流式输出

1. 界面中心的提示语：

由当前时间判断“时间提示语“：
UTC+8 东八区时间
· 06:00 - 09:00: 早上好
· 09:00 - 11:00: 上午好
· 11:00 - 14:00: 中午好
· 14:00 - 17:00: 下午好
· 17:00 - 19:00: 日落了
· 19:00 - 22:00: 晚上好
· 22:00 - 次日 06:00: 夜深了

用户身份提示语：即小程序内用户昵称。
提示语第一行就由这两个要素组成，例如：中午好，健雄用户_XSDJ。; 夜深了，HanJaeJun。

提示语第二行是吴健雄先生的名言：以比第一行文字颜色略淡的文字来显示。有些语录也会有触发时机。以下是语录合集：

General:(该分类的语录，无论何时都有可能触发)
· 世人的眼光或许分男女，微小的原子和核子却不会。
· 不要害怕做新的尝试，即使失败了，也是向成功迈进的一步。
· 真正的智慧不在于知识的多少，而在于运用知识的能力。
· 实验物理是以事实为依据的学问。
· 一个成功的实验需要的是眼光、勇气和毅力。
· 父亲教我做人要做‘大我’而非‘小我’。

在夜深了时段可能会触发的语录：
· 只有一件事比从实验室回到家里看到满池的脏碗更糟糕，那就是不能去实验室。

第二行提示语由这个要素构成，具体来说，例如：“真正的智慧不在于知识的多少，而在于运用知识的能力。” ————吴健雄。字体Size比第一行提示语小。尽量不换行。

下面是一些初始问题展示，用户点击后会自动向聊天框发送该问题：
· 为我介绍一下吴健雄
