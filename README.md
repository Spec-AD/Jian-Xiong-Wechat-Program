对于小程序的后续开发，主要聚焦于以下几点：
整个小程序底部Tab导航可分三个：大厅 | AI | 我的
1.用户资料页（我的）
· 在用户首次登录时，默认生成用户名和唯一uid参数，使用默认头像。

· 用户可以编辑自己的信息，包括但不限于：头像，用户名，签名，生日，地域，兴趣。

· 用户在\*\*第一次”\*\*点击头像或用户名时，调用微信登录接口可快速获取微信头像和昵称。
· 用户的界面应当至少显示头像，用户名，uid。

· 其他信息如签名，生日，地域，兴趣，用户可在隐私设置中自行决定是否展示在界面上。

· 发布数，获赞，浏览量是可点击的，具体效果是：
	· 单击发布数：可查看作品发布情况，时间戳等。内容定向到一个数据中心的页面；

&#x09;· 单击获赞数：可查看自己作品的获赞信息。内容定向到一个数据中心的页面；

&#x09;· 单击浏览量：可查看自己作品的浏览量信息。内容定向到一个数据中心的页面。

· 数据中心内容：又分 4 个 Tab：总览，发布，获赞和浏览。
	· 关于总览：集成所有指标，包括总发布数，总获赞量，总浏览数。一周间发布数，一周间获赞量，一周间浏览数，对应图表。
	· 关于发布：详细介绍发布的情况，包括总发布数，Tag 分布，文件类型，发布趋势，发布趋势图表等

&#x09;· 关于获赞：同发布一样的逻辑；（含点赞用户画像，由浏览用户个人资料的地域，兴趣，生日等统计）
	· 关于浏览：同发布一样的逻辑；（含浏览用户画像，由浏览用户个人资料的地域，兴趣，生日等统计）
	· 设置：通用设置。设置应当包含一切可以闭环的项目，如上文提到的隐私：可以更改信息的可见性；账号与安全；认证；关于等等。
· 关于是否是校内人员的认证：由于该平台不一定只有校内人员使用，故校内师生认定尤为重要：认证通过昵称会变为南大标志紫色，认证方式可通过 P 认证：p.nju.edu.cn，或者 NJU 自己的authorize 认证。
· 并不是谁都可以发布作品：在当前阶段，你可假设发布作品入口被关闭。
· 其他项目：我的点赞，浏览记录，下载项目等。
· 跳转链接：可附上该项目的 GitHub 仓库链接，爱发电链接等。
