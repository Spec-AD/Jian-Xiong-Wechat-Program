---
description: When handling authentication checks and admin permission checks in
  both frontend and backend code
alwaysApply: false
---

需要登录校验的页面/操作，使用 `requireAuth()` 统一函数进行登录拦截（位于 miniprogram/utils/api.ts）。需要管理员权限的操作，后端在 service 层通过 `userRole !== 'admin'` 校验，前端通过 `getUserProfile()` 获取 role 判断。编辑和删除作品的权限仅限管理员（admin）。
