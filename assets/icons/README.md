# 图标资源说明

请在此目录放置以下 tabBar 图标（建议尺寸 81×81px，PNG 格式）：

| 文件名              | 用途              |
|---------------------|-------------------|
| hall.png            | 大厅 tab 默认图标 |
| hall_active.png     | 大厅 tab 选中图标 |
| profile.png         | 我的 tab 默认图标 |
| profile_active.png  | 我的 tab 选中图标 |

颜色建议：
- 默认：#999999（灰）
- 选中：#4A2C6E（紫）
